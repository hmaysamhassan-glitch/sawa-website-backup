# Sawa Art Director

Use this skill whenever designing or materially redesigning a Sawa page.

## North star
Sawa should feel like **editorial intelligence meets a live operating console**:
- premium
- sharp
- technical
- alive
- confident, not loud
- bespoke, not template-driven

The current Start Sawa visual DNA is the baseline. Inspect the existing implementation before changing anything. Preserve the strongest existing choices: dark atmosphere, compact data-console language, monospaced metadata/status labels, and the Grow / Newsletter / Campaign system metaphor. Improve hierarchy, storytelling, credibility, depth, and motion rather than replacing the brand with a different trendy template.

## Before coding
1. Inspect the current homepage components, CSS/Tailwind tokens, fonts, spacing, colors, radii, shadows, and animation patterns.
2. List the 5-8 visual rules that define the current brand.
3. Identify what feels empty, generic, unclear, or under-designed.
4. Use references as principles, not copies:
   - Vercel / Linear / Stripe: restraint, polish, typography, system clarity.
   - The Pudding: story-specific visual ideas.
   - Growth.Design: progressive visual teaching.
   - 21st.dev: interaction/component inspiration.
5. Choose one visual thesis for the page before building it.

## Hard anti-AI-design rules
Do NOT default to:
- purple/blue gradient blobs
- random glassmorphism cards
- generic 3-column icon grids
- floating meaningless particles
- giant pill buttons everywhere
- excessive rounded cards
- stock illustrations
- fake dashboards with fake metrics
- decorative motion that communicates nothing
- copying a 21st.dev component without adapting it into Sawa's system

## Design rules
- Every section must have a reason to exist and a distinct visual idea.
- Use typography, grid, whitespace, linework, status labels, diagrams, and data-like UI to create depth.
- Prefer one strong visual mechanism over five weak effects.
- Use asymmetry when it improves editorial hierarchy.
- Keep the page dense enough to feel substantial, but never cluttered.
- Use the existing accent color/token unless there is a documented reason to change it.
- Never invent client logos, results, testimonials, credentials, or metrics.
- If proof is unavailable, design an honest placeholder state or omit the claim.

## Output expectation
The finished page should feel custom-built for Sawa, not like “AI made a SaaS landing page.”
